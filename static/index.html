A Privacy-Preserving Skill the Agent Can Plan & Invoke

Goal. Diagnose diseases and recommend treatment plans from medical imaging while keeping the user's sensitive data private. Instead of exposing a pile of low-level tools, we package the whole secure pipeline as one skill — and design the framework so an agent can plan it, invoke it, and execute it as secure two-party computation over encrypted data.
